# Contributing

Thanks for taking the time. This is a small, single-maintainer project, so
the bar is deliberately low-key.

## What gets merged

Bugfixes are the priority. Clear reproductions, failing tests, and small
patches that make a real problem go away are welcome and usually merged
quickly.

Large features are a different story. You are free to open a pull request
for one, but please don't treat a PR as a guarantee: bigger changes may sit,
need rework, or be declined. If a feature is substantial, open an issue
first and talk it through before building it.

## How to help

Any of these are useful:

- Fix bugs, add tests, or tighten documentation.
- Triage issues and help keep them clear.
- Fork the project and adapt it to your own needs.

## Practical notes

- Read `AGENTS.md` before changing behavior; it documents the wire protocol,
  design rules, and test instructions. Update it when a change affects those
  contracts.
- Keep changes small and focused. One problem per pull request.
- Add or update tests for the behavior you change.
- Describe what you changed and why in the pull request.
