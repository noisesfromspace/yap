Where should the fold view live?

What the label actually means

Call it a view, not a “fold level”: Yap’s 1–3 are presets, not Neovim’s numeric foldlevel. View 1 keeps user prompts visible; 2 shows the conversation with tools and thinking folded; 3 opens everything. The system prompt stays folded in 1 and 2. Individual folds can still be overridden.

If this ships

  • Read the view from the window, not the buffer: two splits can differ.
  • Keep the indicator on inactive windows only if it helps identify their differing views; otherwise follow the existing quiet inactive-bar policy.
  • Test wide, narrow, and gutterless bars. Drop the long label before sacrificing the usage gauge.
